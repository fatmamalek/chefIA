## 🎯 Description du projet

**ChefIA** est une application web interactive qui utilise un **grand modèle de langage (LLM)** pour générer automatiquement des recettes de cuisine créatives et personnalisées.

L'utilisateur entre les ingrédients qu'il a à disposition, choisit un type de cuisine et un temps de préparation, puis l'IA génère instantanément une recette complète avec :
- La liste des ingrédients avec quantités
- Les étapes détaillées de préparation
- Un conseil du chef

## 🚀 Comment utiliser l'application

### Option 1 — Ouvrir directement (sans installation)
1. Téléchargez le fichier `index.html`
2. Double-cliquez dessus pour l'ouvrir dans votre navigateur
3. Entrez vos ingrédients et cliquez sur **"Générer ma recette"**

### Option 2 — Cloner le projet
```bash
git clone https://github.com/fatmamalek/chefIA.git
cd chefIA
# Ouvrir index.html dans votre navigateur
```
